## Быстрое обновление SafeGram (frontend + backend)

### На ПК

```powershell
cd "C:\Users\Lev\Desktop\Projects\SafeGram restart\web"
npm run build
tar -czf safegram-web-dist.tgz dist
scp safegram-web-dist.tgz root@141.8.198.152:/root/

cd "C:\Users\Lev\Desktop\Projects\SafeGram restart\server-go"
.\build-for-server.bat
scp main Caddyfile start-container.sh start-caddy.sh check-api.sh Dockerfile.prebuilt root@141.8.198.152:/root/safegram-server-files/
```

### На сервере

```bash
mkdir -p /var/www/safegram /root/safegram-server-files
rm -rf /var/www/safegram/*
tar -xzf /root/safegram-web-dist.tgz -C /var/www/safegram --strip-components=1

cd ~/safegram-api/server-go
cp /root/safegram-server-files/main ./main
cp /root/safegram-server-files/Caddyfile ./Caddyfile
cp /root/safegram-server-files/start-container.sh ./start-container.sh
cp /root/safegram-server-files/start-caddy.sh ./start-caddy.sh
cp /root/safegram-server-files/check-api.sh ./check-api.sh
cp /root/safegram-server-files/Dockerfile.prebuilt ./Dockerfile.prebuilt

perl -i -pe 's/^\xEF\xBB\xBF//' start-container.sh start-caddy.sh check-api.sh
sed -i 's/\r$//' start-container.sh start-caddy.sh check-api.sh
chmod +x ./main ./start-container.sh ./start-caddy.sh ./check-api.sh

docker build -f Dockerfile.prebuilt -t safegram-server .
docker rm -f safegram-server 2>/dev/null || true
bash start-container.sh

docker rm -f caddy-safegram 2>/dev/null || true
bash start-caddy.sh
```

### Проверка после обновления

```bash
docker ps --format 'table {{.Names}}\t{{.Status}}\t{{.Ports}}'
curl -s http://127.0.0.1:8080/health
echo
curl -sk https://safegram.site/health
echo
curl -sk https://safegram.site/api/status/summary
echo
curl -sk https://safegram.site/api/maintenance/status
```

Если всё в порядке:
- `127.0.0.1:8080/health` даёт JSON
- `https://safegram.site/health` даёт JSON
- `https://safegram.site/api/status/summary` даёт JSON
- главная, логин, регистрация, календарь и задачи открываются
