# SafeGram Desktop Application

**Самостоятельное** ПК-приложение (как Telegram Desktop): свой интерфейс и сборка, но подключается к **одному серверу и одной БД** SafeGram — те же чаты, серверы, контакты, пользователи.

## 🚀 Особенности

- **Один бэкенд, одна система**: десктоп и веб работают с одним API и одной базой данных.
- **Полный клиент**: чаты (ЛС, группы), серверы и каналы (ServerView), контакты (список/поиск/добавить/удалить), присоединение по ссылке (чат и сервер), поиск, боты, профиль, настройки, админка (пользователи, статистика, аналитика, баны, здоровье системы, техработы), истории.
- **Нативно**: системные уведомления, трей, горячие клавиши, автообновление.
- **Кроссплатформенность**: Windows, macOS, Linux.

## 📋 Требования

- Node.js 18+
- npm или yarn
- Go сервер SafeGram (запущен на http://localhost:8080)

## 🛠️ Установка и запуск

Нужен запущенный **Go-сервер SafeGram** (одна БД, один API). В настройках десктопа или через `VITE_API_URL` укажи URL сервера (по умолчанию `http://localhost:8080`).

### Разработка

```bash
cd desktop
npm install
cd renderer && npm install && cd ..
npm run dev
```

Запустится Vite (renderer на порту 5174) и Electron. Окно откроет локальный клиент.

### Сборка установщика

```bash
cd desktop
npm run build
# или
npm run build:installer
```

Собирается только нужное для приложения: **main/** (main process), **renderer/dist/** (собранный клиент), **package.json**. Исходники (`renderer/src/`, сервер, веб) в пакет не попадают. Результат: `desktop/dist/` — установщик Windows (NSIS), при необходимости macOS (dmg), Linux (AppImage/deb).

**Раздача другим ПК:** один установщик для всех. После установки пользователь в приложении открывает **Настройки → Подключение** и вводит адрес API (например, туннель ngrok или `http://ваш-пк:8080`). Сохранение и перезагрузка — приложение подключается к твоему серверу.

## 🎨 Основные компоненты

### API Client (`core/api/client.ts`)

Профессиональный HTTP клиент с:
- Автоматическими повторными попытками
- Обработкой ошибок
- Таймаутами
- Загрузкой файлов с прогрессом

### WebSocket Manager (`core/websocket/manager.ts`)

Надежный WebSocket клиент с:
- Автоматическим переподключением
- Очередью сообщений
- Ping/Pong для проверки соединения
- Подпиской на события

### Cache Database (`core/cache/database.ts`)

Локальная база данных (IndexedDB) для:
- Кэширования данных
- Офлайн режима
- Синхронизации

## 🔒 Безопасность

- Context isolation включен
- Node integration отключен
- Preload скрипт для безопасного API
- Валидация всех входных данных
- Шифрование локальных данных (планируется)
