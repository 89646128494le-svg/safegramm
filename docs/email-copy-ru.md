# SafeGram Email Copy Pack (RU)

Рабочий набор текстов для транзакционных и сервисных писем SafeGram.

## Принципы

- Тон: спокойный, технологичный, уверенный.
- Без пустых обещаний про "абсолютную анонимность" и "невозможность взлома".
- Security-письма короткие и прямые.
- Продуктовые письма теплые, но без рекламного шума.
- По умолчанию не раскрывать лишние данные пользователя и не отправлять полные тексты переписки по email.

## Быстрые рекомендации по внедрению

1. Сразу включить:
   - `password_changed`
   - `new_device_login`
   - `security_alert`
   - `welcome`
2. Не включать по умолчанию:
   - `new_message_notification`
   - `unread_digest_opt_in`
3. Для billing включать только после реальной платежной логики:
   - `premium_activated`
   - `premium_receipt`
   - `premium_expiring`
4. Для compliance и доверия добавить после стабилизации account settings:
   - `email_change_verify`
   - `email_change_confirmed`
   - `account_export_ready`
   - `account_deleted_confirmed`
