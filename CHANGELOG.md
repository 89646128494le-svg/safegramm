# Changelog

Все значимые изменения проекта SafeGram описываются в этом файле.

## [Unreleased]

### Добавлено
- Платежи: вебхуки Stripe и ЮKassa, модель Payment, дашборд доходов и конверсии в админке
- PWA: manifest.webmanifest, офлайн-страница, кэширование в Service Worker
- CI: GitHub Actions — сборка и тесты Go, сборка и линт фронта на PR/push в main
- Боты: публичная документация API (OpenAPI), webhook входящих сообщений, лимиты по токену
- Compliance: экспорт данных пользователя (GDPR), удаление аккаунта с каскадом

### Изменено
- Резервное копирование БД: скрипт backup-db.sh по DATABASE_URL
- Метрики и логи: /metrics, файловый лог с ротацией, HSTS в production

## [1.0.0] — ранее

- Базовый мессенджер: чаты, E2EE, Safety AI, админка, премиум-планы
